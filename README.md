# Odin Recipes

A basic recipe website built for [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

This project practices HTML document structure, headings, paragraphs, images, links, unordered lists, ordered lists, and relative file paths. It intentionally uses **HTML only**, without CSS or JavaScript.

## Recipes

- Lasagna
- Pancakes
- Guacamole

## Run locally

Open `index.html` in a web browser. Follow the recipe links and use the **Home** link to return to the index.

## Project notes

The recipe illustrations are original SVG assets created for this exercise. The assignment suggests using free photos of the finished dishes; these illustrations are placeholders and can be replaced with photos later if you want to match that requirement exactly.
